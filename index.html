📋 Data Format Requirements

The dashboard accepts the standard BSC AMS & IMS Daily Productivity Tracker Excel file:

  • Sheet name: Sheet1, Daily Log, or any sheet — auto-detected
  • Header row: auto-detected (looks for Date, Agent Name, SAP ID columns)
  • Required columns: Date, Day, SAP ID, Agent Name, Level, Portfolio/Stream, IM Total, Non-IM Total, Grand Total
  • Format: One row per agent per day
  • Supports both September and October (or any month) tracker files

New data is merged with any previously loaded data — upload multiple months and all will reflect in the dashboard.
